# NeoNASAChallenge

Dashboard per esplorare asteroidi vicini alla Terra usando dati NASA.

## Stack
- Backend: Python + FastAPI
- Frontend: Next.js (App Router)
- Data source: NASA APIs (`https://api.nasa.gov/`)
